# Інтерактивний урок: Задачі на оптимізацію в Excel — 10 клас

## Файли
- `index.html` — інтерактивна сторінка учня: теорія, приклад, практика, тест та оцінювання за 12-бальною шкалою.
- `teacher.html` — окрема методична сторінка вчителя: паспорт уроку, сценарій на 45 хв, критерії, відповіді, диференціація.
- `Шаблон_Excel.xlsx` — готові таблиці для двох задач.
- `README.md` — ця інструкція.

## Система оцінювання
6 балів — правильна математична модель; 4 бали — тест; 2 бали — виконання двох кроків у Excel. Самопозначки Excel бажано підтвердити перевіркою файлу.

## Публікація на GitHub Pages
1. Створіть репозиторій GitHub.
2. Завантажте всі файли в корінь репозиторію.
3. Відкрийте Settings → Pages.
4. У Build and deployment оберіть Deploy from a branch, гілку `main` і папку `/ (root)`, натисніть Save.
5. Учнівська сторінка: `https://ваш-логін.github.io/назва-репозиторію/`.
6. Сторінка вчителя: додайте до адреси `teacher.html`.

Сторінки працюють без зовнішніх бібліотек та інтернет-залежностей. Назви пунктів Excel можуть відрізнятися залежно від версії та мови інтерфейсу.
